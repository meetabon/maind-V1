ЧТО ЭТО ЗА ПРОЕКТ
================================================================================

Минимально жизнеспособная нейроморфная система с:
- Жёсткой энергетикой (сложность = дороже)
- Локальным обучением (без глобальной оптимизации)
- Эволюцией мета-параметров (наследуются способы, не знания)
- 3D средой с динамическими изменениями
- 8 областями нейронов (подкубы 4×4×4)

ЦЕЛЬ: Реализовать систему, которая учится выживать в изменяющейся среде
через локальную адаптацию и эволюцию алгоритмов обучения.

================================================================================
АРХИТЕКТУРА СИСТЕМЫ
================================================================================

СРЕДА:
- 3D пространство 8×8×8 со значениями {-1, 0, +1}
- Медленный дрейф: каждые 100 шагов меняется 10% ячеек
- Катастрофы: каждые 500 шагов локально меняется 20% ячеек

НЕЙРОНЫ:
- 8 областей по 64 нейрона (подкубы 4×4×4)
- Каждый нейрон привязан к ячейке среды
- Бинарная активация {0,1}, случайные пороги [0.1, 0.9]
- 95% локальные связи, 5% дальние межобластные

ЭНЕРГЕТИКА:
- Начальная энергия = количество_нейронов × 0.5
- Затраты: активность (0.01), веса (0.001), дальние связи (0.05)
- Доходы: поглощение +1 ячеек активными нейронами
- Штраф за ошибки предсказания

ОБУЧЕНИЕ:
- Правило Хебба: Δw = η·a_i·a_j - γ·|w|
- Примитивные ожидания через скользящее среднее
- Мета-параметры: η (обучение), λ (вес ошибки), склонность к дальним связям

ЭВОЛЮЦИЯ:
- Триггер размножения: рост ошибки + падение энергии
- Мутация мета-параметров ±10%
- Смерть старой системы, рождение новой

ОЖИДАЕМОЕ ПОВЕДЕНИЕ
================================================================================

НАЧАЛЬНАЯ ФАЗА (0-500 шагов):
- Высокая активность, быстрая трата энергии
- Случайные веса, высокие ошибки предсказания
- Постепенная адаптация к локальным паттернам среды

АДАПТАЦИЯ (500-2000 шагов):
- Снижение активности, стабилизация энергии
- Формирование локальных связей
- Уменьшение ошибок предсказания

КРИЗИС И РАЗМНОЖЕНИЕ (переменно):
- При изменениях среды - рост ошибок
- Падение энергии из-за неадаптированности
- Триггер размножения → новое поколение

ЭВОЛЮЦИЯ (многие поколения):
- Отбор более адаптивных мета-параметров
- Улучшение способности к обучению
- Возможное появление дальних связей

================================================================================
ОТЛАДКА И МОНИТОРИНГ
================================================================================

КОНСОЛЬНЫЙ ВЫВОД:
- Каждые 1000 шагов: энергия и средняя ошибка
- При размножении: уведомление о смене поколения
- При смерти: причина остановки

CSV АНАЛИЗ:
- Графики энергии и ошибок во времени
- Корреляция между активностью и выживанием
- Эволюция мета-параметров по поколениям

ТИПИЧНЫЕ ПРОБЛЕМЫ:
- Быстрая смерть → слишком высокие энергозатраты
- Нет размножения → слишком мягкие условия триггера
- Постоянные ошибки → среда слишком хаотична
