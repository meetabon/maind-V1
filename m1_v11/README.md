# M1 v1.1 - Нейроморфная система

Минимально жизнеспособная нейроморфная система с жёсткой энергетикой, локальным обучением и эволюцией мета-параметров.

## Быстрый старт

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск симуляции
python main.py

# Или альтернативный запуск
python run_example.py
```

## Архитектура системы

### 3D Среда
- **Размер**: 8×8×8 пространство со значениями {-1, 0, +1}
- **Динамика**: Медленный дрейф каждые 100 шагов (10% ячеек)
- **Катастрофы**: Локальные изменения каждые 500 шагов (20% ячеек)

### Нейронная структура
- **8 областей**: Каждая область = подкуб 4×4×4 нейронов
- **Локальность**: Каждый нейрон привязан к своей ячейке среды
- **Связи**: 95% локальные, 5% дальние межобластные

### Энергетическая система
- **Начальная энергия**: N_нейронов × 0.5
- **Затраты**: Активность (0.01), веса (0.001), дальние связи (0.05)
- **Доходы**: Поглощение +1 ячеек активными нейронами

### Обучение и эволюция
- **Локальное обучение**: Правило Хебба с регуляризацией
- **Мета-параметры**: η (обучение), λ (ошибка), склонность к дальним связям
- **Размножение**: При росте ошибки + падении энергии

## Ключевые особенности v1.1

✅ **Жёсткая энергетика** - сложность стоит энергии  
✅ **Локальное обучение** - без глобальной оптимизации  
✅ **Эволюция способов** - наследуются алгоритмы, не знания  
✅ **Примитивные ожидания** - тупое скользящее среднее  
✅ **Безопасность** - без протопамяти и внутренних символов  

## Результаты

Система создаёт CSV файл `m1_v11_results.csv` с метриками:
- `step`: номер шага
- `energy`: текущая энергия
- `avg_error`: средняя ошибка предсказания
- `long_links`: количество дальних связей
- `self_aware`: самосознание (зарезервировано)
- `total_activity`: общая активность нейронов
- `total_weights`: сумма весов связей
- `generation`: номер поколения

## Условия остановки

- **Смерть**: Энергия ≤ 0
- **Лимит**: 10,000 шагов
- **Деградация**: Рост ошибки >1000 шагов

## Размножение

Триггеры:
1. Ошибка растёт (>20% от недавнего среднего)
2. Энергия падает (<10% от максимума)

Действие:
- Мутация мета-параметров (±10%)
- Создание новой системы
- Смерть старой системы
